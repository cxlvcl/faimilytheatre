# Театр музыки и песка

Сайт семейного театра: афиша, репертуар, статьи, франшиза. Проект сделан мной целиком, от базы данных до вёрстки, и работает в продакшене.

**Сайт:** [театрмузыкиипеска.рф](https://театрмузыкиипеска.рф)
Публичная часть театра. Афиша и репертуар берутся из API, страницы рендерятся на сервере для SEO.

**Цифровой буклет:** [театрмузыкиипеска.рф/canvas](https://театрмузыкиипеска.рф/canvas)
Страница, на которую ведёт QR-код из печатного буклета. Картины в 3D-рамах на three.js, работает и без JavaScript.

## Что внутри

- `api/` — REST API на чистом PHP без фреймворка: свой роутер, валидация, авторизация по сессиям, rate limiting, загрузка файлов, SEO-хранилище.
- `database/` — схема MySQL и миграции.
- `web/` — фронтенд на React 19, TypeScript и Vite с серверным рендерингом.
- `canvas/` — цифровой буклет (TypeScript, three.js, модели рам из Blender).
- `cron/`, `deployment/`, `scripts/` — фоновые задачи, конфиги хостинга и сборка релиза.
- `tests/` — тесты API, SEO и фронтенда.
