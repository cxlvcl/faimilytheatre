# Обновление сайта: ближайшие даты, фото меню, вход в админку

Для уже работающего сайта `театрмузыкиипеска.рф` на server281.hosting.reg.ru.
Это не повторная установка: **базу не импортировать, config.php не заменять,
uploads не трогать, пароли и DNS не менять**.

Что входит в обновление:

- на главной после видео — раздел «Ближайшие даты»: две ближайшие даты из афиши
  с постером, кратким описанием и кнопкой «Купить билет»;
- новое фото в меню (на телефоне — отдельный вертикальный кадр);
- исправление админки: она больше не выкидывает на «Сессия завершена»
  (сервер передаёт ключ входа в PHP — файл `api/.htaccess` в папке сайта и `Request.php`);
- всё из обновления 1 октября (статьи, видео на главном экране и т. д.).

Порядок строгий: **01 → 02 → 03**. Все файлы из одной папки `REG-RU-REFRESH-…`.

## 1. Резервная копия

В ispmanager сохраните копию текущих файлов **вне публичного каталога сайта**:

- `~/www/private/api/`, `~/www/private/manifest.json`, `~/www/private/ssr/`;
- `~/www/xn--80aanbjgaodo1bgudcs1l.xn--p1ai/media/` и `fonts/`.

Файлы в `assets/` не удалять: они нужны открытым вкладкам и для отката.

## 2. База данных — не требуется

Таблица `articles` создана 2 октября; база в этом обновлении не меняется.
Файл **00-database-articles.sql** лежит в пакете только для новых установок:
если таблицы `articles` вдруг нет, выполните его в phpMyAdmin (вкладка SQL).
Повторное выполнение безопасно — команда только создаёт таблицу, если её нет.

## 3. Публичные файлы — 01-public-update.zip

Откройте `~/www/xn--80aanbjgaodo1bgudcs1l.xn--p1ai/`, загрузите
**01-public-update.zip** и распакуйте **в текущую папку** с заменой.
В архиве `assets/`, `fonts/`, `media/` (в том числе три видео главного
экрана, ~17 МБ), значки `favicon.ico`, `favicon-96.png`, `apple-touch-icon.png`
и `api/.htaccess` — он заменит существующий файл в папке `api` сайта.
Папки объединяются с существующими: удалять их целиком нельзя.

На этом шаге сайт ещё работает в старой версии.

## 4. Серверная часть — 02-private-update.zip

Откройте `~/www/private/`, загрузите **02-private-update.zip** и распакуйте
**сюда** с заменой. Обновляются PHP API и `ssr/`.

## 5. Включение — 03-activate-update.zip

Оставаясь в **`~/www/private/`**, загрузите **03-activate-update.zip** и
распакуйте с заменой (`manifest.json` и `api/seo/`). Этот шаг включает новую
версию сайта. Внутри `private/` не должно появиться второй папки `private/`.

После установки удалите с сервера три загруженных ZIP-архива.

## 6. Проверка

Напишите «загрузил всё» — сайт проверяется запросами HTTP: главная с видео,
статьи, sitemap, API, значок сайта. Затем откройте сайт на телефоне и на
компьютере и посмотрите сами.

## Админка на Mac

Новая админка с разделом «Статьи» — файл `Theatre-Admin-mac.dmg`
(отдельная папка `ADMIN-MAC-…`, инструкция внутри). Старую программу
можно удалить и поставить новую. Работает с этим же сервером, вход — тем же
логином и паролем.

## Откат

Верните из резервной копии `private/api/`, `private/manifest.json`,
`private/ssr/`, `media/`, `fonts/`. Таблицу `articles` удалять не нужно:
старая версия сайта её просто не использует.

## Повторная сборка на Mac

```sh
export PATH="$PWD/.local-tools/node-v22.23.2-darwin-x64/bin:$PATH"
npm run build -w web
node scripts/package-refresh-update.mjs
```
