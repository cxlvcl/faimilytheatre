# Обновление сайта: цифровой буклет «Ожившие шедевры» (/canvas)

Для уже работающего сайта `театрмузыкиипеска.рф` на server281.hosting.reg.ru.
Это не повторная установка: **базу не импортировать, config.php не заменять,
uploads не трогать, пароли и DNS не менять**.

Что входит в обновление:

- новая страница **`/canvas`** — цифровой буклет концерта «Ожившие шедевры»: 18 картин
  в 3D-рамах, текст открывается по нажатию на картину. Её открывают по QR-коду из буклета;
  в меню и в sitemap её нет, поисковикам закрыта;
- кнопка «Купить билет» внизу страницы берёт ближайшую дату «Ожившие шедевры» из афиши;
  если даты нет, кнопки нет;
- всё, что было в предыдущем пакете (заставка без двойного логотипа и др.), если его ещё не загружали.

Порядок строгий: **01 → 02 → 03**. Все файлы из одной папки `REG-RU-REFRESH-…`.
**SQL не нужен**, если SEO-обновление уже ставилось (таблицы `seo_meta`, `site_settings`
есть в базе). Файл `00-database.sql` безопасен и при повторном выполнении.

## 1. Резервная копия

В ispmanager сохраните копию текущих файлов **вне публичного каталога сайта**:

- `~/www/private/api/`, `~/www/private/manifest.json`, `~/www/private/ssr/`;
- `~/www/xn--80aanbjgaodo1bgudcs1l.xn--p1ai/media/` и `fonts/`.

Файлы в `assets/` не удалять: они нужны открытым вкладкам и для отката.

## 2. Публичные файлы — 01-public-update.zip

Откройте `~/www/xn--80aanbjgaodo1bgudcs1l.xn--p1ai/`, загрузите
**01-public-update.zip** и распакуйте **в текущую папку** с заменой.
Внутри `assets/` появится папка `assets/canvas/` — картины, рамы, фоны, скрипт страницы
и QR-код (`assets/canvas/qr-canvas.svg`). Папки объединяются с существующими: удалять их целиком нельзя.

На этом шаге сайт ещё работает в старой версии.

## 3. Серверная часть — 02-private-update.zip

Откройте `~/www/private/`, загрузите **02-private-update.zip** и распакуйте
**сюда** с заменой. Обновляются PHP API и `ssr/`, появляется папка `private/canvas/`
(шаблон страницы и тексты картин).

## 4. Включение — 03-activate-update.zip

Оставаясь в **`~/www/private/`**, загрузите **03-activate-update.zip** и
распакуйте с заменой (`manifest.json` и `api/seo/`). Этот шаг включает новую
версию сайта и адрес `/canvas`. Внутри `private/` не должно появиться второй папки `private/`.

После установки удалите с сервера три загруженных ZIP-архива.

## 5. Проверка

Напишите «загрузил всё» — сайт проверяется запросами HTTP. Затем откройте на телефоне
`https://театрмузыкиипеска.рф/canvas` и поверните пару картин пальцем.

## После загрузки

- **QR-код для буклета** — `assets/canvas/qr-canvas.svg` (в пакете и на сайте по адресу
  `/assets/canvas/qr-canvas.svg`). Ведёт на `https://xn--80aanbjgaodo1bgudcs1l.xn--p1ai/canvas?utm_source=booklet`.
  Передайте дизайнеру как есть, SVG масштабируется без потери качества.
- **Старая страница на Tilda** `tmip.tilda.ws/canvas`: в настройках страницы Tilda поставьте
  перенаправление на `https://театрмузыкиипеска.рф/canvas`, чтобы старые QR-коды вели на новую страницу.
- **Метрика**: цель `canvas_open_text` (открыли текст картины, параметр — какая картина) создайте
  в Яндекс Метрике как JavaScript-событие с этим идентификатором.

## Откат

Верните из резервной копии `private/api/`, `private/manifest.json`,
`private/ssr/`, `media/`, `fonts/`. Папки `assets/canvas/` и `private/canvas/` старой версии
сайта не мешают.

## Повторная сборка на Mac

```sh
export PATH="$PWD/.local-tools/node-v22.23.2-darwin-x64/bin:$PATH"
npm run build -w web
npm run build -w canvas
node scripts/package-refresh-update.mjs
```
