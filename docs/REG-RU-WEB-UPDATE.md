# Обновление фонового видео без кнопки Play

Эта поставка меняет только собранный интерфейс и его манифест.
Она не меняет базу, PHP, пароли, DNS, сертификат, фотографии или видеофайлы.
HDR и резервное видео 4K остаются прежними, перекодирования нет.

## Что изменено

- Запуск запрашивается после появления фона во вступительной анимации.
- До фактического воспроизведения поверх видео показан отдельный постер без кнопок.
- Встроенные элементы управления отключены; добавлены защитные стили для Safari.
- Если браузер отклоняет автозапуск, остаётся постер. После обычного клика/касания
  или нажатия клавиши на странице выполняется ещё одна попытка без отдельной кнопки.
- При ошибке поддержки/декодирования HDR один раз выбирается существующее видео H.264 4K.
- Уменьшение движения, скрытая вкладка и прокрутка за пределы первого экрана
  по-прежнему останавливают фоновое видео.

Запрет браузера на автозапуск нельзя гарантированно отменить кодом сайта.
Визуальный результат необходимо проверить в Safari на Mac после загрузки.

## Установка — сначала assets, затем manifest

Работать в **ispmanager → Менеджер файлов** на server281.hosting.reg.ru.

1. Открыть корень сайта:

   `~/www/xn--80aanbjgaodo1bgudcs1l.xn--p1ai/`

2. Загрузить `public-update.zip` и распаковать **в эту папку**, не создавая дополнительный каталог.
   В архиве только папка `assets`. Если панель спрашивает о совпадающих файлах,
   разрешить замену файлов из этого архива. **Старую папку assets целиком не удалять**:
   старые файлы нужны вкладкам, открытым до обновления, и для отката.

3. Перейти в соседнюю приватную папку:

   `~/www/private/`

4. Скачать существующий `manifest.json` на Mac как резервную копию.
   Не менять `config.php` и остальные файлы в private.

5. Загрузить сюда `private-update.zip` и распаковать **в текущую папку**,
   заменив только `manifest.json`. Вторая папка private внутри private не нужна.
   Это действие включает новую сборку, поэтому выполнять его только после шага 2.

6. После распаковки можно убрать с сервера только эти два загруженных ZIP-архива;
   локальные архивы сохранить. Это не обязательное условие работы обновления.

7. Открыть https://театрмузыкиипеска.рф/ в Safari и перезагрузить страницу.
   Проверить первый заход с анимацией и повторный заход, отсутствие кнопки Play,
   воспроизведение при разрешённом автозапуске и статичный постер при его запрете.
   Отдельно проверить уменьшение движения, переход в другую вкладку и возврат.

Если после обновления нужна старая сборка, вернуть сохранённый `manifest.json`
в `~/www/private/`. Старые assets оставлены, поэтому файлы сайта и базу
для такого отката перезаливать не требуется.
